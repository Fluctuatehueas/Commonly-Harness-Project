# 本文档介绍归档功能

Time: 2026-11-05

---

## 一、什么是归档？

当用户拥有大量使用记录时，就会难免遇到会话数量过多，导致用户界面看起来很混乱。并且如果大量临时的会话存在，并且仅是很短的时间内对用户有用，那么这些会话不适合长期再UI界面展示。因此需要引入归档功能，目的就是做减法。  

归档，可以认为是将会话终止，结束这段对话，并且对用户不在有任何意义。可以理解为物业中的**软删除**。


## 二、归档功能介绍

### 2.1 软删除会话
用户进行会话归档后，将不会再对话界面左侧栏的会话组、项目组中看到本次会话，但是会话记录和日志仍会在数据库中或本地磁盘保留。  

### 2.2 归档会话管理
用户可以在归档会话管理页面查看所有已归档的会话，并进行一些操作
- 恢复归档会话  
即将该归档会话恢复到UI显示的位置，用户可以再次看到它
- 删除归档会话  
永久删除该归档会话，包括会话记录和日志。删除时提示用户
- 查看归档会话的内容  
用户可以查看归档会话的内容，但是不可以进行任和交互，仅作[聊天记录]式的查看。  
查看归档会话时，需要和正式的聊太难界面区分开。
- 如果时本地项目相关的会话，应当可以定位到是在哪一个本机磁盘位置。数据库村的就不用。

### 2.3 设置归档会话计时器
- 用户可以按需要，决定一个会话在多久不产生新记录后就自动归档。  
- 每次检测计时仅在用户切换到展示聊天界面时进行一次检测。不要后台真的开启多个计时器浪费CPU资源。
- 默认值30天

> 归档的会话，不再被Agent访问到。
