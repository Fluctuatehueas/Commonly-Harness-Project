# 对外接口文档

本目录提供该系统对外拓展的接口文档，按接入方角色拆分。

| 文档 | 内容 | 读者 | 暴露范围 |
| :-- | :-- | :-- | :-- |
| [MCP服务接入API.md](./MCP服务接入API.md) | 甲方后端把业务系统封装为 MCP 服务、并提供 RAG 知识库时必须实现的接口与工具契约，含 Python / Java / C# / Go 示例 | 甲方后端开发 | 甲方自有服务 |
| [业务主链路API.md](./业务主链路API.md) | 对话、会话、反馈、附件、轨迹、异步任务、会话文件 | 甲方后端 / 前端开发 | 可经网关对外 |
| [管理与配置API.md](./管理与配置API.md) | MCP 服务、RAG Provider、设置、MyAgent、技能、任务流、项目 | 甲方后端 / 运维 / 管理员 | 仅内网或管理员 |

> 运行期自动生成的 OpenAPI（Swagger）文档：启动后端后访问 `http://127.0.0.1:8000/docs`。
> 所有接口都通过 `X-User-Id` 识别用户，网关必须先剥离客户端自带的身份头再注入可信值。
