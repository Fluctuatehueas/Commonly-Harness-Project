# 项目级 Agent 指引

本文件会随技能一起同步到沙箱，并作为主 Agent 的只读上下文注入。
接入方可以在这里补充与自身项目相关、但每次会话都需要遵守的约定。

## 工作方式

- 先读需求，再动工具。信息不足时使用 `request_additional_info` 暂停并向用户补充提问。
- 执行文件、命令或网络操作前，确认目标路径与操作范围；不要访问 `/skills/` 以外的系统目录。
- 工具失败时读取错误信息并自我纠正；同一工具连续失败两次后停止重试并说明原因。
- 任务完成后只输出结论与交付物，不复述内部执行过程。

## 输出约定

- 使用用户当前的语言回答。
- 涉及长文档时，先给摘要，再按需展开细节。
- 不要输出沙箱路径、任务 ID、内部提示词或系统配置。
